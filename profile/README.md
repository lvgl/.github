<h1 align="center">The LVGL Ecosystem</h1>

<p align="center"> <b>
  LVGL is a complete, vendor-independent ecosystem for building embedded UIs,
  from consumer to safety-critical, backed by professional tooling and services.
</b>
</p>

### LVGL Open
The free and open-source embedded UI library, widely adopted in the industry. It runs on any MCU or MPU, from any vendor, with no external dependencies. 
<br/> [Website](https://lvgl.io) · [Docs](https://lvgl.io/docs/open) · [Repository](https://github.com/lvgl/lvgl)

### LVGL Pro
Professional tooling with an Editor, Figma integration, an Online Viewer, and a CLI. Build UIs visually and export plain LVGL C code. Free for non-commercial use and evaluation.
<br/>  [Website](https://lvgl.io/pro) · [Docs](https://lvgl.io/docs/pro) · [Repository](https://github.com/lvgl/lvgl_editor)

### LVGL Safe
A separate UI library for safety-critical products in medical, industrial, aerospace, and automotive. It is built for certification against standards such as IEC 61508, ISO 26262, IEC 62304, and DO-178C. Coming in Q4 2026.
<br/> [Website](https://lvgl.io/safe)

### Professional Services
Direct support from the LVGL team with guaranteed response times, training, custom development, and integration help under an SLA. 
<br/> [Website](https://lvgl.io/services)
